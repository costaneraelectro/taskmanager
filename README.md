# Daily Task Manager

App de una sola página: `index.html`. Se publica con GitHub Pages en
https://costaneraelectro.github.io/taskmanager2/

- Datos: Firebase `taskmanager-ebec9`, documento `paneles/{uid}` y adjuntos
  en `paneles/{uid}/adjuntos`. Reglas en `reglas-firestore.txt`.
- `sw.js`: service worker para mostrar los avisos.
- Íconos: `icono.svg` es el original; los PNG salen de él.
